# Installing and publishing v0.3.0

Sovereign Local Core is an MIT-licensed database engine, published as source and
an installable `sovereign-local-core-0.3.0.tgz` artifact on GitHub. The artifact
contains browser ESM entry points, TypeScript declarations, a self-contained
Worker with embedded WASM, the asset-copy CLI and documentation. Applications
need no C++ toolchain or postinstall compilation.

## Install the GitHub release

```sh
npm install https://github.com/5645hm-a11y/sovereign-local-core/releases/download/v0.3.0/sovereign-local-core-0.3.0.tgz
```

Import `sovereign-local-core`, `sovereign-local-core/react` or the optional
`sovereign-local-core/nostr`. [Quick start](../README.md#quick-start) and
[Worker/Next.js/CSP configuration](DX.md) cover integration. Release assets
include SHA-256 checksums and a manifest binding the tarball to the source commit.
GitHub autogenerated source archives are source distributions, not NPM bundles.

## NPM registry status

Registry publication is separate from the GitHub release. This environment is
not authenticated to NPM, so the package is prepared but has not been uploaded
to the registry. Until that publication, use the GitHub artifact above.
After an authenticated owner publishes it, the normal command is:

```sh
npm install sovereign-local-core
```

The release owner can publish the exact tested archive without rebuilding:

```sh
npm login
npm whoami
npm publish ./artifacts/sovereign-local-core-0.3.0.tgz --access public --tag latest
npm view sovereign-local-core@0.3.0 version dist.integrity
```

The repository sets `publishConfig.access` to `public` and uses an explicit
artifact whitelist. Authenticate directly with NPM; credentials are not part
of source, the release assets or the package. Account permissions, the package
name and any registry-required second factor must permit publication.

## Rebuild and validate from source

```sh
npm ci
npm run build
npm test
npm run test:browser
npm run test:dx
npm run check:release
npm pack --pack-destination artifacts
npm publish ./artifacts/sovereign-local-core-0.3.0.tgz --dry-run --access public --ignore-scripts
```

Development builds need the documented Emscripten SDK, Node and Python versions.
`test:dx` installs the archive into Vite and Next.js fixtures, checks declarations,
SSR/Strict Mode and Worker cleanup. CI runs the unit, browser and installed-package
suites and scans committed source for credentials. Query benchmarks have explicitly
narrow timing scopes; see [incremental-index measurements](INCREMENTAL_INDEXES.md).

Version 0.3.0 remains experimental. Publishing an artifact does not change its
[security boundaries](../SECURITY.md), finite [resource limits](SCALABILITY.md)
or the distinction between provisional offline invariant outcomes and finality.
